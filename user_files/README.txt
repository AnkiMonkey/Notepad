Notepad by AnkiMonkey – user_files
==================================
Anki keeps this folder when the add-on is updated.

templates/   your TXT templates. File name = tag or deck, with "::" replaced by "__"
             (tag Pharma::Antibiotics -> Pharma__Antibiotics.txt).
             default.txt is used when nothing else matches.
             Examples: templates/_example_*.txt (rename to use them).
